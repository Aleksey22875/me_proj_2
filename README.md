# me_proj_2
Консольный калькулятор — это C++ CLI-приложение, которое выполняет арифметические операции через аргументы командной строки. Входные параметры парсятся через getopt, после чего программа определяет операцию и вызывает соответствующую функцию из подключаемой библиотеки. Поддерживаются сложение, вычитание, умножение, деление, возведение в степень и факториал. Внутри реализованы проверки корректности входных данных и условий выполнения операций; при ошибках выполнение прерывается через механизм возврата статусов, при корректных данных программа продолжает выполнение до завершения расчёта.

Сборка проекта выполняется через CMake:

mkdir build
cd build
cmake ..
make

Запуск:

./calculator -x 2 -y 3 -o +
./calculator -x 2 -y 3 -o ^
./calculator -x 5 -o !

Проект собирается как CMake-based система, где основная логика вынесена в отдельную библиотеку, подключаемую как зависимость из GitHub, после чего устанавливается и используется в Linux-окружении как консольный инструмент.
